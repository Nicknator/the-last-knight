# ⚔️ Skybound

An epic, responsive 2D arcade side-scroller browser game built with pure vanilla JavaScript (OOP) and HTML5 Canvas. Take control of a brave knight fighting against waves of dangerous monsters and a mighty flying dragon boss!

## 🎮 Game Description
In **The Last Knight**, players navigate through a treacherous winter landscape. Armed with a sharp sword for close combat and a powerful mechanical crossbow, you must collect valuable coins, replenish your ammunition, and defeat all skeleton enemies before facing the ultimate flying dragon boss. 

*Note: This project was originally titled "The Last Knight" and has been updated with the theme "Skybound". Both names refer to this official version.*

## 🚀 Features
* **Magical Aiming Mechanics:** Crossbow bolts automatically tilt 45 degrees upward when approaching the flying dragon boss for enhanced combat fluidness.
* **Single-Trigger Combat System:** Smooth melee sword attacks that execute completely with a single, short press of the `E` key (inspired by classic RPGs like *The Witcher*).
* **Fully Responsive Mobile Interface:** Advanced CSS grid gamepad engine with automatic YouTube-style fullscreen landscape lock layout for seamless gaming on smartphones and tablets.
* **Highly Optimized Assets:** Sprite sizes and background images compressed by over 75% for ultra-fast loading times.

## 🛠️ Tech Stack & Architecture
* **Language:** Vanilla JavaScript (ES6+)
* **Rendering Engine:** HTML5 Canvas API (Object-Oriented Programming Structure)
* **Styling:** CSS3 Media Queries & Flexbox Grid Matrix
* **Audio:** Compressed MP3 soundboard layer pipelines

## ⌨️ Controls
* `A` / `D` - Move Left / Right
* `W` - Jump
* `S` - Shield Block (Down)
* `E` - Melee Sword Attack
* `F` - Crossbow Shoot

## ⚙️ Local Installation & Setup

Follow these simple steps to clone this repository and run the game locally on your machine for testing or development purposes:

1. **Clone the Repository:**
   Open your terminal/command prompt and run the following command to download the project files:
   ```bash
   git clone https://github.com/Nicknator/the-last-knight.git
   ```

2. **Navigate into the Directory:**
   Move into the project folder using the command line:
   ```bash
   cd the-last-knight
   ```

3. **Run the Game Locally:**
   Since this project is built using pure Vanilla JavaScript and HTML5 without any external dependencies, you don't need to run `npm install`. 
   
   To launch it, you have two simple options:
   * **Option A (Recommended):** Open the project folder in VS Code, install the extension **Live Server**, right-click on `index.html`, and select **"Open with Live Server"**. This prevents local browser CORS blockades for audio/image assets.
   * **Option B:** Simply double-click the `index.html` file inside your file explorer to open it directly in any modern web browser.
